One app.
Three jobs.

Trinity replaces your phone's Phone, Messages and Contacts apps with a single app in one calm, glassy look. No ads, no trackers, no account — just your own data, in one place.

What it does.

01 / CALLS

Calls, considered.

Call log grouped by person with direction, duration and time. Dial pad, in-call controls, call screen takeover, and a short summary when a call ends. Unknown numbers are matched to saved contacts even in a different format.

02 / MESSAGES

Messages, your way.

Threads grouped by person, quick reply from notifications, scheduled texts, JSON export/restore, and optional on-device semantic search. Picture messages work too — no text ever leaves your phone.

03 / CONTACTS

Contacts, complete.

Per-person call and message history, contact photos saved straight to the phone, favourites, groups, a Google-sync indicator, and a find-duplicates sheet that links rather than deletes.

04 / BLOCKING

Quiet by rule.

Name, number, keyword and combined rules with AND/OR, time windows and wildcards. Blocked texts are held aside, never silently dropped. Rules export as a JSON pack with a preview before import.

05 / HOME

Always in reach.

An optional widget shows unread messages, missed calls today and held texts — each count opens its own screen. A quick settings tile toggles unknown-caller screening.

06 / PRIVACY

Only on your phone.

No ads, no trackers, no telemetry, no account. Optional on-device language model runs locally and is off until you enable it. Updates check GitHub once and can be skipped for any version.

The details.

StackKotlin · Java · Material Expressive — a hybrid glass UI with one look in light and dark, the same on every screen.
RequiresAndroid 8.0 (API 26) or newer. Trinity replaces the Phone, SMS and Contacts roles, so Android asks you to confirm which app handles each.
BuildJDK 17+ · Android SDK platform 34. ./gradlew assembleRelease → app/build/outputs/apk/release/app-release.apk. Release builds are signed with the debug key so they install and update over themselves.
StatusWork in progress, not released on any store. Install the latest APK from GitHub Releases.
