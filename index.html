About

I study computer science in Peshawar, Pakistan. Most of what I write is JavaScript, TypeScript, Python and shell: API bridges, tool-calling layers, and the glue that makes coding agents usable outside a browser tab.

My usual machine is a Redmi Note 11 running a full Kali Linux chroot, so I spend a lot of time on the unglamorous side of software — memory ceilings, missing systemd, binaries that refuse to exec — and it has made me fairly ruthless about dependencies.
